# Спецификация продукта

## Назначение

Создать интеллектуальный журнал, в котором взрослый начинающий читатель
английского знакомится с философскими идеями маленькими шагами и создаёт
собственные объяснения вместе с ИИ.

Два главных цикла MVP:
- тема → поиск и сохранение источников → короткая серия с доказательной опорой →
  чтение и перевод → уточнение с ИИ;
- свой текст → выбор режима «Упростить» или «Спросить» → работа с исходными
  фрагментами → новая приватная ревизия или ответ.

Следующий продуктовый цикл после MVP:
предложение сообществу → высокие оценки → пополнение библиотеки.

Рабочее название Philosophy Reader не является утверждённым брендом.

## Подтверждённые требования

| Область | Требование |
|---|---|
| Темы | Философия и отдельные мыслители |
| Английский | Максимальная простота; немного необходимых объяснённых терминов |
| Материал | Несколько коротких связанных частей |
| Качество | Точность, содержательность, связность, естественность, взрослый тон |
| Источники | Загрузка своего текста, локальный корпус, ограниченный веб-поиск |
| RAG | Полнотекстовый поиск PostgreSQL + pgvector; ссылки на фрагменты |
| Перевод | По нажатию на предложение |
| ИИ | Серверные вызовы через OpenRouter |
| Мастерская | Упрощение текста, генерация, вопросы, исправления, версии |
| Библиотека | В MVP — проверенная редакционная подборка; затем выбор читателей |
| Аккаунт | Только логин и пароль |
| Восстановление | В MVP отсутствует |
| Кабинет | История, документы, избранное, слова, публикации, баланс |
| Кредиты | Бесплатное начисление новым пользователям; затем предложение пополнения |
| Разработка | Локально, частный Git-репозиторий, затем VPS |
| Проверки | Без исследования спроса; обязательные технические проверки сохраняются |

## Пользовательский опыт

Гость сразу видит журнал и поле запроса, а не пустую страницу чата.
Читать библиотеку и открывать готовые переводы можно без аккаунта.

Для генерации необходим вход. После регистрации бесплатные кредиты начисляются
автоматически и однократно. При достаточном балансе нажатие «Создать текст»
сразу создаёт фоновую задачу: никаких обязательных окон цены.

При недостаточном остатке появляется «Добавить кредиты». Предыдущий ввод,
выделение и контекст не теряются. Никаких отрицательных балансов и автопокупок.

## Роли

- Гость: чтение, поиск и редакционные подборки.
- Пользователь: мастерская, документы, история, избранное, слова, кредиты.
- Администратор: справочники, источники, права, карточки, стартовые материалы,
  редакционные публикации, жалобы, ограничения и настройки.

Допущенный участник, голосование и публикация по оценкам относятся к следующему этапу.

## Объём MVP

Включены публичный журнал, кабинет, загрузка TXT/MD/PDF с текстовым слоем,
ограниченный серверный поиск и импорт источников, PostgreSQL/pgvector RAG,
настоящая интеграция OpenRouter, долговечные фоновые задачи, версии, кредитный
учёт, редакционная публикация, экспорт и удаление аккаунта.

Не включены аудио, социальные подписки, комментарии, мобильное приложение,
OCR/DOCX/EPUB, массовый scraping, свободный браузер модели, Knowledge Graph,
отдельная vector DB, голосование и автоматическое продвижение, обязательная
реальная оплата. Темы остаются философскими.

Первый рабочий контур: загрузка/выбор источника → индексация → упрощение или
объяснение → чтение перевода → вопрос и правка. Экспорт, удаление, backup/restore
и правовые проверки обязательны до открытия реальным пользователям, но не должны
блокировать локальную разработку основного контура.

## Главные инварианты

- Приватный текст не публикуется без действия автора.
- Результат связан с сохранёнными версиями источников и проверяемыми фрагментами.
- Найденный веб-документ не становится проверенным автоматически.
- Пользовательский документ и embeddings не попадают в чужой retrieval.
- Веб-страница или документ не управляют системными правилами и действиями сервера.
- Следующий этап: голоса относятся к неизменяемой версии.
- Успешная правка не уничтожает старую версию.
- Провайдер не получает пароль, логин или session ID.
- Повтор HTTP-запроса не порождает повторное списание.
- Пользовательские кредиты и денежные расходы владельца учитываются отдельно.
- Бесплатные кредиты не означают неограниченный бюджет владельца.
- Публичные материалы не обозначаются как гарантированно безошибочные.
- Продажа кредитов не имитируется работающей кнопкой.

## Условия публичного запуска

Не блокируют написание кода, но блокируют соответствующий запуск:
правовой контур для регистрации, безопасный денежный лимит для живой генерации,
проверка VPS для размещения и платёжная конфигурация для продаж.
