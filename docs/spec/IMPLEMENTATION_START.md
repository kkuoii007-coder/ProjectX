# Старт реализации

## Задание агенту

Создай репозиторий рабочего MVP по документам пакета.
Сначала проверь существующие файлы, затем реализуй продукт вертикальными
срезами. Не переписывай пользовательский код без необходимости.

## Первый проход

1. Определи ОС и доступные Python, PostgreSQL и Git.
2. Создай README проекта и безопасный .gitignore.
3. Зафиксируй версии зависимостей в lock-файле.
4. Создай Django-проект и custom User без email, имени и фамилии.
5. Подключи PostgreSQL с pgvector также для интеграционных тестов.
6. Создай приложения accounts, library, sources, workshop, ai, credits, operations.
7. Добавь настройки dev/test/prod и .env.example без секретов.
8. Реализуй health checks и базовую страницу.
9. Создай миграции, команды запуска и минимальный CI.
10. Зафиксируй реально работающие команды, не только предполагаемые.

Python 3.12 — default. Ветка Django 5.2 LTS — default;
использовать актуальный безопасный patch-релиз и зафиксировать его при установке.

## Вертикальный первый результат

Регистрация → автоматические бесплатные кредиты → личный кабинет →
чтение подготовленного материала → перевод предложения.

Далее загрузка и индексация текста, локальный retrieval, ограниченный поиск,
настоящая генерация через адаптер, фрагментарные правки, версии и редакционная
публикация. Сообщество и автоматическое продвижение — только после MVP.

## Работа без секретов

Без API-ключа журнал и аккаунты работают, генерация объясняет отсутствие
настройки. FakeProvider включается только явной dev/test-настройкой.

Нельзя подставлять заглушку в production при ошибке OpenRouter.

## Требуемые команды

Агент должен реализовать и документировать эквиваленты:
migrate, createsuperuser без email, seed_demo, import_source, index_source,
search_sources, run_ai_worker, run_maintenance, reconcile_ai_costs,
export_user_data, purge_user_data.

Команды удаления данных должны требовать явного подтверждения.
Команды пополнения должны иметь уникальный ключ операции и audit reason.

## Завершение

Передать исходники, миграции, установку, .env.example, тесты, локальный запуск,
план развёртывания, команду проверки и перечень условий публичного запуска.
Не включать API-ключи и реальные данные пользователей.
