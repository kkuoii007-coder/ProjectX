# Пакет спецификаций Philosophy Reader

Версия: 1.2  
Дата: 8 ноября 2026 года  
Назначение: передать кодинг-агенту для создания рабочего MVP.  
Язык документации и интерфейса: русский.  
Язык основных материалов: английский. Перевод: русский.

## Что создаётся

Интеллектуальный журнал для чтения философии на максимально простом английском:
публичная библиотека, личная ИИ-мастерская, упрощение загруженных текстов,
перевод предложений, сохранение слов и версии с опорой на конкретные источники.
Источники пополняются локальным RAG и ограниченным серверным веб-поиском.
Голосование и отбор пользовательских материалов — следующий этап после MVP.

Нужен работающий продукт, а не макет, не только frontend и не демонстрация с
подставными ответами ИИ.

## Изменения версии 1.2

Добавлены загрузка пользовательских текстов, локальное хранилище источников,
ограниченный серверный веб-поиск и RAG на PostgreSQL с pgvector. Подробности:
[источники и RAG](docs/sources-and-rag.md), [конвейер ИИ](docs/ai-pipeline.md).

Найденный документ не считается автоматически авторитетным или свободным для
копирования. Модель получает только извлечённые сервером фрагменты и не имеет
свободного браузера, инструментов публикации или доступа к секретам.

Голосование и автоматическое продвижение перенесены следующим этапом. В MVP
библиотека наполняется через явную редакционную публикацию.

## Кредитный UX

После регистрации пользователь автоматически получает бесплатные кредиты.
Перед генерацией и каждой правкой нет обязательного экрана с ценой и
подтверждением списания. Пользователь работает с ИИ непосредственно.

Баланс доступен в интерфейсе, правила расхода доступны в справке.
Если кредитов недостаточно для следующего действия, система сохраняет запрос
и предлагает добавить кредиты. Пополнение не запускает сохранённый запрос само.

## Статусы решений

- «Подтверждено»: прямо следует из требований владельца.
- «Default»: принято в пакете для устранения неопределённости; можно менять настройкой.
- «Условие запуска»: требует реального решения владельца до публичной эксплуатации.

Цифры кредитов, рейтингов и лимитов — defaults, а не результаты исследования.
Не выдавать их за экономически проверенные величины.

## Границы пакета

Это комплект документов, не исходный код сайта.
Платёжный провайдер и юридические реквизиты не выдуманы.
Реальная продажа кредитов выключена по умолчанию.
Локальная разработка не должна ждать выбора платёжного провайдера.

## Перед публичным запуском

Обязательно определить допустимый денежный бюджет, модель OpenRouter,
правовой контур, реальное размещение данных и достаточность ресурсов VPS.
Не обещать, что отсутствие email исключает обработку персональных данных.
