# Эксплуатация и администрирование

## Панель администратора

Нужны разделы:
карточки знаний, мыслители, темы, подборки, editorial publications,
источники, права, версии документов, ошибки индексации и retrieval,
жалобы и заблокированные материалы; кандидаты — после MVP,
кошельки и транзакции только через сервисные действия,
задачи, неопределённые попытки, дневной бюджет, системные переключатели.

Не редактировать wallet баланс напрямую полем формы.
Начисление требует amount, reason и уникального operation_key.
Показать отдельные суммы total/reserved/available.

Не добавлять admin action обхода голосования для community publication.
Редакционная публикация имеет собственное действие и маркировку. В MVP она требует
валидный QualityReport для content hash, проверенные карточки, покрытые ключевые
утверждения и допустимые права на источники. Исходный приватный документ не
публикуется вместе с производной ревизией без отдельного решения и прав.

## Наблюдаемость

Собирать:
число задач по состояниям,
время ожидания и выполнения,
ошибки адаптера, поиска, fetch и индексации,
число документов/chunks и время embeddings,
резервы и фактические расходы,
остаток бюджета,
неопределённые costs,
диск, RAM, DB connections,
успех backups,
число жалоб; после MVP — число кандидатов.

Это служебные метрики, не публичная выдуманная аналитика.
Не включать тексты, пароли и полные prompts в метрики.

## Проверки состояния

/live/: процесс отвечает.
/ready/: база доступна и миграции применены.

Отдельный служебный статус: worker heartbeat и live AI configuration.
Недоступность OpenRouter не должна делать публичную библиотеку недоступной.

## Maintenance

Периодически:
освобождать корректно завершённые резервы,
разбирать истёкшие leases без слепого повторного вызова,
обрабатывать прерванную индексацию без слепого повторного вызова,
после MVP — продвигать кандидатов,
удалять истёкшие сессии и rate-limit данные,
выполнять политику удаления,
контролировать денежные расхождения.

## Инциденты

Утечка ключа:
выключить live AI, отозвать ключ, проверить расходы, заменить секрет.
Не считать удаление ключа из последнего Git commit достаточным.

Рост расходов:
circuit breaker останавливает новые задачи;
чтение и кабинет остаются доступны.
Незавершённые задачи объясняются пользователям.

Сбой Hermes:
не перезапускать его из приложения сайта.
Диагностировать изоляцию и ресурсы по согласованному runbook.

## Аудит

Сохранять причины ручных начислений, скрытия, аннулирования голосов,
изменения порогов и включения платёжного режима.
Аудит не должен содержать пароль или весь пользовательский диалог.
