# Голосование и публикация — следующий этап

Этот документ не входит в реализацию MVP. До его начала endpoints submissions/votes
и автоматическое продвижение не включаются. В MVP доступна только редакционная
публикация через admin по [ai-pipeline.md](ai-pipeline.md). Ниже — согласованный контур будущего
расширения, а не причина создавать сообщество раньше основного контура источников.

## Принцип

Пользовательские тексты входят в библиотеку благодаря высоким оценкам.
Администратор не обязан лично утверждать каждый текст.
Структурные, языковые и фактические ворота действуют до голосования.

## Предложение

Автор выбирает конкретную ревизию, видит публичный preview и подтверждает
предложение. Диалог, первоначальный запрос и история правок остаются приватными.

Состояния:
pending_checks → candidate → published.
Альтернативы: ineligible, withdrawn, blocked.

Одна ревизия имеет одно submission.
Default: не более трёх активных кандидатов от аккаунта.

## Defaults голосования

- Оценка 1–5.
- Один голос аккаунта на submission.
- Автор не голосует.
- Возраст аккаунта для голосования — не менее 24 часов.
- Не более 20 новых голосов в сутки.
- До публикации оценку можно изменить.
- После публикации итоговые голоса замораживаются; остаются жалобы.

Это ограничение простейшей накрутки, не подтверждение уникальности человека.
Не обещать защиту от множества аккаунтов.

## Продвижение

Одновременно должны выполняться:
не менее 10 допустимых голосов,
средняя оценка >= 4.5,
доля оценок 4–5 >= 80%,
возраст candidate >= 72 часов,
валидный quality report,
проверенная фактическая основа,
отсутствие блокирующего moderation hold.

Пороговые значения — конфигурация, не доказанная оптимальная модель.
На карточке показывать реальное число голосов.

## Конкурентность

Vote и promotion блокируют submission в одинаковом порядке.
Повтор promotion не создаёт вторую публикацию.
У Publication уникальная связь с submission.
Нельзя публиковать head проекта вместо revision из submission.

После голосования автор может сделать новый приватный вариант.
Его голоса начинаются заново; старые не переносятся.
Для замены кандидата старый отзывается явным действием.

## Жалобы

Категории: фактическая ошибка, слишком сложно, плохой перевод,
неприемлемый контент, права на текст, другое.

Одна неподтверждённая жалоба не должна автоматически скрывать материал:
это позволило бы блокировать тексты злоупотреблением.
Moderation hold выставляет администратор либо отдельное обоснованное правило.
Default: три новые жалобы в сутки на аккаунт.

Накрутка не определяется только IP: общий адрес не доказывает общее лицо.
Аннулирование голосов сохраняет audit reason.

## Стартовая библиотека

Начальные материалы маркируются «Редакционная подборка».
Пользовательские — «Выбрано читателями».
Не выдумывать голоса для начальных текстов.

Высокая оценка означает читательское одобрение, не экспертное подтверждение истины.
