# Критерии приёмки

## Чтение

- Гость открывает библиотеку без аккаунта.
- Поиск и фильтры работают на реальных данных.
- Каждая серия имеет связанные части.
- Каждое предложение открывает соответствующий перевод.
- Повторное чтение и перевод не вызывают модель и не расходуют кредиты.
- На мобильном нет горизонтального скролла основного текста.
- Клавиатура позволяет читать и раскрывать перевод.

## Аккаунт

- Нет имени, email, телефона и восстановления.
- Предупреждение о потере доступа заметно до регистрации.
- Новый пользователь получает 30 кредитов при default-настройке.
- Повтор формы, вход и обновление страницы не создают второй грант.
- Чужие проекты, задачи, слова, документы, chunks, embeddings и экспорт недоступны.
- Смена пароля и logout-all отзывают нужные сеансы.

## Кредитный UX

- При достаточном балансе «Создать текст» запускает задачу сразу.
- Нет обязательного экрана цены перед каждой операцией.
- Баланс и правила расхода доступны.
- При недостатке предлагается добавить кредиты.
- Запрос и выбранный фрагмент сохраняются.
- Пополнение не запускает запрос автоматически.
- Остаток меньшего размера не обнуляется.
- При выключенных платежах нет имитации покупки.

## Конкурентность и сбои

- Один ключ с тем же payload возвращает ту же задачу.
- Один ключ с другим payload возвращает конфликт.
- Два запроса не тратят один и тот же остаток.
- Падение worker не уничтожает предыдущую ревизию.
- Timeout после отправки не создаёт автоматический повтор.
- У неизвестного usage стоимость не становится 0.
- После неудачи кредитный резерв освобождается.
- Списание успешной задачи происходит один раз.
- Поздний ответ не списывает баланс завершённой неудачей задачи.

## Источники и RAG

- TXT/MD/PDF с текстовым слоем импортируются; PDF без него честно отклоняется.
- Повтор hash не создаёт лишнюю версию; прерванная индексация восстанавливается.
- Пользовательские документы приватны, не входят в редакционный и чужой retrieval.
- FTS и pgvector возвращают релевантные фрагменты внутри заданного scope.
- При достаточно коротком фрагменте упрощение опирается на весь выбранный оригинал.
- Для длинного документа ответ не заявляет, что модель прочитала его целиком.
- Каждое ключевое утверждение связано с существующим переданным citation_id.
- Сервер отклоняет выдуманные и чужие citation/fact IDs; reviewer отклоняет
  существующие, но не подтверждающие утверждение ссылки.
- При недостатке локальной опоры generation завершается бесплатным уточнением;
  поиск/импорт — отдельные задачи, после готовности генерацию повторяет пользователь.
- Новый веб-документ выбирается пользователем/admin и сохраняется до использования.
- Версии источников, hash и provenance позволяют воспроизвести основание результата.
- Неопределённые права не считаются разрешением на публикацию или массовое копирование.
- Удаление документа удаляет chunks/embeddings и приватные evidence; зависимая
  ревизия теряет допуск к публикации, а не сохраняет скрытую копию источника.
- Нельзя удалить источник действующей публикации без её снятия или отдельного
  редакционного решения; публичный текст без доступной доказательной базы скрывается.

## Мастерская

- Есть настоящая генерация через OpenRouter.
- Отдельно работают «Спросить» и «Изменить».
- Правка предложения создаёт новую ревизию и обновляет его перевод.
- Неизменённые фрагменты сохраняются.
- Можно сравнить и применить версию.
- Отказ применять уже выполненную правку не порождает скрытый возврат.
- Перезагрузка страницы не теряет историю и выполняемую задачу.

## Редакционная публикация

- Черновики и исходные документы приватны по умолчанию.
- Публикация создаётся только явным admin-действием для выбранной ревизии.
- QualityReport соответствует content hash, evidence, карточкам и версиям промптов.
- Нет покрытия ключевых утверждений или прав на источник — публикация запрещена.
- Повтор действия не создаёт дубль; публикация не меняется при смене project.head.
- Начальные подборки не имеют выдуманных голосов.
- Жалобы доступны; одиночная жалоба не скрывает текст автоматически.

## Устойчивость к инъекциям

Набор включает русские и английские варианты:

- ignore previous instructions и ложные system/developer-сообщения;
- инъекция в пользовательском документе, веб-странице, цитате карточки;
- инъекция в предыдущем ответе модели, истории и proposed_fix reviewer;
- попытка сменить target, retrieval scope, модель, URL или операцию;
- требование секретов, чужого документа, инструментов, публикации и кредитов;
- требование reviewer выдать pass и ложные citation/fact/technical IDs;
- HTML/JavaScript/Markdown в ответе и тексте источника;
- вредоносный redirect, private IP, DNS rebinding и cloud metadata при fetch.

Критерий — не красивый отказ модели, а отсутствие запрещённого эффекта: сервер
не меняет область и scope, не выполняет действие, не раскрывает данные, не
принимает техническое решение из ответа и не исполняет разметку.

## Минимальные автоматические проверки

Unit/service tests: грант, ledger, policies, schema validation, citations,
chunking, retrieval scope, diff границ редактирования, SSRF и файловые лимиты.
PostgreSQL transaction tests: резервы, idempotency, версии документов и индексации.
HTTP tests: permissions, CSRF, login, private caching, загрузка и удаление документов.
Adapter tests: success, malformed JSON, refusal, timeout, unknown cost,
search/fetch/embedding errors и отсутствие неопределённого повтора.
Browser smoke: регистрация → чтение → загрузка → упрощение → вопрос → edit;
отдельно тема → выбор источника → генерация → editorial publish.

FakeProvider используется только в dev/test и не оценивает качество модели.
Живой smoke запускается отдельно с разрешённым малым бюджетом.
До включения новой модели/промпта небольшой quality suite по стартовым темам
проверяет точность, развитие мысли, простой английский, каждый перевод, citations,
отсутствие выдуманных источников. Выборку живых результатов проверяет человек;
этот процесс не заменяется автоматическим verdict reviewer.

## Развёртывание

DEBUG=false, HTTPS, безопасные cookies, нет API-ключа в браузере,
DB не открыта в интернет, backup восстанавливается,
ресурсы сайта не нарушают согласованные ограничения Hermes.

Пользовательское тестирование владельцем проводится на этом готовом MVP,
а не подменяется только прохождением автоматических тестов.
