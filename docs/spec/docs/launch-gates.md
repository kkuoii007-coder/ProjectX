# Условия запуска

## Локальная разработка

Разрешена сразу: без внешних пользователей, продаж и живых секретов.
Документы не требуют предварительных интервью и исследования спроса.
Проверки критической логики входят в разработку.

## Закрытый технический MVP

Нужны настроенный сервер, секреты и реальный ограниченный бюджет,
если выполняются живые запросы.

Закрытый тест сам по себе не отменяет правовых обязанностей при работе
с реальными людьми. Не использовать слово «тест» как юридическое освобождение.

## Публичная регистрация

Владелец определяет:
свой статус и юрисдикцию,
географию аудитории,
фактическое размещение баз и backups,
обработчиков запросов и условия OpenRouter, embedding provider и Search API,
передачу фрагментов пользовательских документов этим обработчикам,
применимость локализации, трансграничной передачи и уведомлений.

Кодинг-агент не должен подписывать политику от имени несуществующей компании
и не должен утверждать, что логин/пароль «не персональные данные».

До решения публичная регистрация закрыта конфигурацией.
Сам UI и локальный сценарий регистрации должны быть полностью реализованы.

## Живые генерации

Нужны реальные generation/review/embedding model IDs,
проверенные возможности endpoints, Search API и правила fetch,
небольшой корпус с документированными правами,
token limits и верхние ценовые пределы,
дневной и месячный бюджет,
один worker, rate limits, аварийное отключение.

Без этого библиотека работает, но генерация честно недоступна.

## Реальные платежи

Нужны продавец, провайдер, валюта, пакеты,
подтверждение webhooks, правила возвратов и потери доступа.

Отдельно учесть: купленные кредиты нельзя восстановить при забытом пароле.
Крупное предупреждение на регистрации не заменяет корректных условий продажи.
До готовности продавать ничего нельзя.

## Публичная библиотека

Стартовые материалы проверены на структуру, перевод и редакционный стандарт.
Есть реальные карточки, сохранённые версии источников и правила жалоб.
Права на хранение, обработку и публикацию материалов проверены отдельно.
Нет фиктивных оценок, отзывов и обещаний сертификации A1.

## Инфраструктура

Есть разрешение на изменения VPS, измерения ресурсов,
изолированный пользователь, HTTPS, backup вне сервера,
успешная проверка восстановления и рабочий rollback.

Условия запуска не должны превращаться в бессрочную паузу разработки:
агент реализует функции и отдельно отмечает выключенные deployment flags.
