# Продукт и интерфейс

## Главная

Заголовок: «Сложные идеи. Простой английский».
Подзаголовок: «Читайте философию небольшими частями.
Упрощайте свои тексты и создавайте объяснения с опорой на источники».

Две явные вкладки: «Объяснить тему» и «Загрузить текст».
Поле темы: «О какой философской идее вы хотите прочитать?»
Пример: «Объясни концепцию вечного возвращения Ницше».
Кнопка: «Создать текст».

Во вкладке «Загрузить текст»: вставка текста или файл TXT/MD/PDF, предупреждение
о приватности и правах, выбор «Упростить этот текст» или «Спросить по тексту».
Если локальных источников по теме мало, генерация без списания предлагает поиск.
Пользователь запускает его отдельно, видит происхождение кандидатов и выбирает
документ для импорта. После готовности документа он повторно нажимает «Создать
текст»; фоновая генерация не ждёт выбора и не возобновляется автоматически.
Произвольный URL не обещает успешную загрузку: показываются ограничения прав,
типа и безопасности.

Ниже: редакционные подборки, новые материалы,
мыслители. Не показывать фиктивные рейтинги, посещаемость и отзывы.

## Кредитный сценарий

После регистрации: «Вам начислено 30 бесплатных кредитов».
Число подставляется из настройки, не дублируется в шаблоне.

В шапке кабинета виден доступный баланс. При наличии резервов можно раскрыть
«Доступно / в работе». Нельзя путать доступный остаток с общим.

Обычное действие запускается сразу.
Нет модального окна с ценой и нет цены на каждой кнопке.
В справке и при первом знакомстве объяснить, что действия используют кредиты.

При нехватке: «Недостаточно кредитов для этого действия».
Кнопки: «Добавить кредиты», «Продолжить чтение».
Если продажи отключены, сообщить, что покупка недоступна. В закрытом тесте
владелец начисляет кредиты через admin/management command; пользовательская
кнопка не имитирует платёж или самостоятельное пополнение.

## Читалка

Узкая колонка текста, навигация по частям, английские заголовки,
русское название и пояснения при необходимости.
Нажатие, Enter или Space раскрывают русский перевод конкретного предложения.
Перевод — готовые данные, без нового платного вызова.

Для материала с источниками доступны название, тип источника и ссылка на оригинал;
необработанный приватный документ другим пользователям не показывается.

Слова можно сохранять с контекстом.
Если перевод слова отсутствует, допускается добавить его вручную.

## Мастерская

Desktop: текст и панель диалога рядом.
Mobile: переключение «Текст / Обсуждение» без потери состояния.

Выбор области: серия, часть, предложение.
Быстрые действия: проще, точнее, пример, ошибка.
Свободная инструкция обязательна.

Режим «Спросить» возвращает объяснение, режим «Изменить» — новую ревизию.
Не изменять текст от обычного вопроса без намерения пользователя.

## Дизайн и доступность

Редакционная типографика, нейтральный фон, один акцент,
без детской геймификации. Начальный UI может обходиться без изображений.

Предусмотреть focus states, контраст, подписи полей, aria-live для статусов,
ошибки рядом с полями, работу с клавиатуры и ширину экрана от 360 px.

Никаких фальшивых процентов готовности. Показывать реальные этапы задачи.
